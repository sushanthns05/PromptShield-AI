# PromptShield AI

Adaptive Runtime Security Gateway for LLM Applications.

## Objective
Detect and mitigate prompt injection, sensitive information
leakage and unauthorized tool actions.

## Core Technologies
- Python
- FastAPI
- Scikit-learn
- PostgreSQL
- React
- Docker

## Research Focus
Context-aware threat detection and adaptive security
policy enforcement for LLM applications.

## Project Status
Research and initial development.
